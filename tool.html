🧬 Digital Karyotyping (Bioinformatics)

Pipeline used in real analysis:
FASTQ Reads → FastQC → Trimmomatic → BWA Mapping → HTSeq Count → CNVkit → Digital Karyotype

Select Gene (Training Dataset)

TP53 = Deletion model | MYC = Amplification model | EGFR = Copy Gain model
Step 1 — FastQC
Quality check for sequencing reads.
Step 2 — Trimmomatic
Trim adapters & low-quality bases.
Step 3 — BWA Mapping
Align reads to reference genome.
Step 4 — HTSeq Counting
Count mapped reads per gene.
Step 5 — CNVkit
Detect copy number variation.
🎯 Final Digital Karyotype
